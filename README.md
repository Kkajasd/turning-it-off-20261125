One funny single line, under 200 characters — a hopeless tech support agent's reply to a desperate customer:

> Have you tried turning it off and on again? Lovely — that was step one of forty-seven, and I'm afraid steps two through forty-six are also turning it off and on again.

`main.ts` (Node 22) composes the line live at run time from three beats — the classic fix, the escalation to forty-seven steps, the punchline that every remaining step is the same fix again — and writes it to `/output/entry.txt`. The program validates the gate itself: UTF-8 text, 1–199 characters, exactly one line, not only whitespace.

## Entry

The joke lands because the agent is cheerfully useless: the one fix every customer already knows turns out to be the entire support playbook, repeated forty-six more times. The customer is never the butt of it — the agent's breezy confidence is.

## Run it

```sh
node main.ts
```
